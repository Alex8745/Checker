## 🧠 Что это

Расписание на сайте школы обновляет админ, когда ему вздумается — вручную, без всякого уведомления. Узнать об изменении можно было только одним способом: заходить и проверять самому.

**Schedule Checker** делает это за тебя: раз в 5 минут скачивает актуальные файлы расписания, сравнивает их с предыдущей версией и, если что-то поменялось — присылает свежую картинку прямо в чат с ботом. Никаких сайтов, никаких «а вдруг поменялось».

## ✨ Возможности

- 🔍 Автоматическая проверка файлов расписания каждые **5 минут**
- 🖼 Рассылка в виде готовой картинки (PDF → PNG), а не ссылки на скачивание
- 🤝 Самостоятельная подписка/отписка через `/start` и `/stop` — без ручного добавления людей
- 🔐 Список подписчиков хранится в репозитории в **зашифрованном виде**
- 🧹 Самоочистка — если человек заблокировал бота, он автоматически перестаёт получать рассылку
- 🌐 Работает бесплатно на GitHub Actions — своего сервера не требуется

## ⚙️ Как это устроено

```
cron-job.org  ──(раз в 5 минут, POST)──▶  GitHub Actions (workflow_dispatch)
                                              │
                                              ▼
                                   checker.py запускается
                                              │
                    ┌─────────────────────────┼─────────────────────────┐
                    ▼                         ▼                         ▼
          Скачивает файлы с          Сравнивает MD5 с        Проверяет новые
             Google Drive             сохранённым                команды
                                        значением              /start, /stop
                    │                         │                         │
                    └───────────┬─────────────┴─────────────┬───────────┘
                                ▼                            ▼
                     Если изменилось — рассылает      Обновляет список
                        PNG всем подписчикам             подписчиков
                                │                            │
                                └────────────┬───────────────┘
                                             ▼
                              Коммитит hashes.json и
                                subscribers.enc обратно в репозиторий
```

Планировщик `schedule` в самом GitHub Actions **намеренно не используется** — он работает нестабильно (best-effort, может задерживаться на часы). Вместо этого внешний бесплатный сервис [cron-job.org](https://cron-job.org) каждые 5 минут дёргает workflow напрямую через GitHub API (`workflow_dispatch`), гарантируя предсказуемый интервал.

## 🛠 Технологии

| Компонент | Используется для |
|---|---|
| **Python 3.12** | основная логика |
| `requests` | скачивание файлов, работа с Telegram Bot API |
| `pdf2image` + `Pillow` | конвертация PDF-расписания в PNG |
| `cryptography` (Fernet) | шифрование файла подписчиков |
| **GitHub Actions** | исполнение проверки по запросу |
| **cron-job.org** | внешний надёжный планировщик |
| **Telegram Bot API** | рассылка и приём команд `/start` / `/stop` |

## 🤖 Бот

Подписаться на уведомления может любой желающий:

1. Открыть чат с ботом
2. Нажать **Start** (или отправить `/start`)
3. Готово — при следующем изменении расписания придёт уведомление с картинкой

Отписаться — командой `/stop` в любой момент.

## 🔒 Приватность

Список подписчиков (`subscribers.enc`) хранится в репозитории в зашифрованном виде — даже при полном доступе к коду прочитать, кто именно подписан, невозможно без отдельного секретного ключа, который никогда не публикуется.
